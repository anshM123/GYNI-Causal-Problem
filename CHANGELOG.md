# Changelog

## 2.0 (2026-10-21)
- New `manuscript/`: the article prepared for Nature Communications. It contains the main text with Methods, Data and
  Code availability, four figures and two tables, and the Supplementary Information (Supplementary Notes 1–8). The
  figures are generated by `manuscript/figures/make_figures.py`.
- Removed the earlier letter-format paper (`paper/`, available in the git history) and the internal working log.
- The README is reorganised as a companion to the article, with a table that maps each claim to its certificate,
  verifier and Lean theorem.
- `logs/coord_verify_*.log` are renamed `logs/independent_verify_*.log`. Their content is unchanged.
- The mathematical content, certificates, code and Lean project are unchanged.

## 1.x (2026-09-28 to 2026-09-29)
- **2026-09-29.** The upper bound is machine-checked in Lean 4 (`lean/GYNIUpper/`, theorem
  `GYNIUpperBound.gyni_upper_bound`). Both ends of the interval are now formally verified.
- **2026-09-28.** Independent re-run of the Lean lower-bound check from a clean build: all 198 files exit 0, standard
  axioms only.
- **2026-09-28, tightened upper bound.**
  - The level-8 certificate was re-derived from the same numerical solution with a 100-fold smaller margin
    (ε = 10⁻⁹), giving `cert3_L8_e9.pkl`: I_GYNI ≤ 0.622183755532.
  - The certified program, the verifier and the proof are unchanged.
- **2026-09-28, decimal rounding.**
  - Every verifier compares exact rationals, and the certificates did not change. Earlier README versions printed
    some decimals rounded to nearest, in the unsafe direction.
  - Corrected values:
    - the J = 4 lower bound is ≥ 0.622165901353, not "≥ 0.622165901354";
    - the level-4 and level-6 bounds are 0.6233558 and 0.6222569;
    - the J = 3 value to nine digits is 0.622146712.
  - The verifiers now print directed-rounded decimals (lower bounds down, upper bounds up).
- **2026-09-28.** Release 1.0: letter and supplemental material, MIT licence, Zenodo and citation metadata.

# GYNI upper bound: Lean log

Goal: a machine-checked upper bound on the GYNI causal inequality,
`gyniValue W M N ≤ 175129158097837 / 2^48` for every finite-dimensional strategy (the level-8
certificate `publish/GYNI-Causal-Problem/src/cert3_L8_e9.pkl`), and first the level-2 bound.

Toolchain: Lean `v4.33.1`, Mathlib from the existing `.lake` (no rebuild, no `lake update`).
Files of this formalisation: `GYNIUpper/UB*.lean`, `GYNIUpper/UpperBound.lean`,
`GYNIUpper/AxiomsUpper.lean`, `GYNIUpper/L2/`, `GYNIUpper/L8/`, `GYNIUpper/tools/`,
`GYNIUpper/data/`, `GYNIUpper/logs_upper/`, `GYNIUpper/check_upper.sh`. The `Lueders*` files
(Lemma 1, `GYNIUpper.lueders_normal_form`) belong to the other formalisation and are only imported.

## Design

### 1. The certificate is made symmetry-free before it enters Lean

The shipped certificates are dual solutions of the program of `mc3.build(L, sym=True)`: rows V2
(class-difference rows) and S (invariance under `fx`, `fy`, `sw`). Proving the S rows sound needs
Lemma 5 (symmetry of Lüders-form strategies and group averaging). Instead, the dual solution is
averaged over the symmetry group (`tools/averaged_cert.py`), which removes the S rows exactly:

1. `Y_k` (the four dual blocks) are computed exactly from the multipliers, as in
   `certify2.verify_exact` (integers `16 D Y_k`).
2. `Y' = |GG|⁻¹ ∑_{g ∈ GG} g·Y` over the group `GG` generated by the signed permutations `fx`, `fy`,
   `sw` (order 8, computed). The averaging operator kills every S-row functional (`φ - φ∘g`
   averages to 0), keeps the objective, maps V2 functionals to V2 functionals and keeps positive
   definiteness.
3. `Φ := o + Y'` (a tensor over the four register blocks; `o` = objective tensor). Then
   `o = Φ - Y'` exactly, and the certificate is used in the form:
   * (CA) for every Bob pair `q` and every Alice class `t ≠ e`: `∑_{p of class t} Φ[p, q] = 0`;
   * (CB) the same with the parties exchanged;
   * every register block of `Y' = Φ - o` is positive semidefinite;
   * `β = ∑_{p, q of class e} Φ[p, q]` (the total trace of `Φ`).

Exact results (Python, `averaged_cert.py`): level 2 (`data/cert3_L2.pkl`, produced in this work with
`certify3.py`, margin `1e-7`; `tools/make_cert.py`): 9 classes, (CA) and (CB) hold, blocks positive
definite, `β₂ = 724501749922913/2^50` = `λ·b`. Level 8 (`cert3_L8_e9.pkl`): 33 classes, (CA) and
(CB) hold, `β₈ = 175129158097837/2^48` = `λ·b` exactly (8.7 s, 1.3 GB). The headline bound is
therefore unchanged. The relaxation certified in Lean is the one without the S rows (its feasible
set contains the symmetric one); no symmetry statement is needed anywhere in Lean.

### 2. The proof in Lean

For a Lüders-form strategy `(W, P, Q)` (process on `(H_A × (H_A × Fin 2)) × (H_B × (H_B × Fin 2))`,
projective measurements, Lüders instruments with setting register) and the word table of level `L`:

* Lemma 2 (`trace_kron_of_scalar`, `UBScalarTrace.lean`): `Tr_out C_A = λ_A 1`, `Tr_out C_B = λ_B 1`
  ⇒ `Tr[W (C_A ⊗ C_B)] = λ_A λ_B` (spanning by CPTP Choi matrices with an explicit perturbation bound).
* Fact (F4) (`ptraceOut_pairChoi`, `UBBasic.lean`): `Tr_out |w', r⟩⟨w, r| = (π(red(w⁻¹ w')))ᵀ`.
* `v2_identity` (`UBMoment.lean`): if `Tr_out C_p` depends only on a class and is `1` on the class
  `e`, then every `Φ` with vanishing class sums satisfies
  `∑ Φ p q Tr[W (C_p ⊗ D_q)] = ∑_{p, q of class e} Φ p q` (this is (V2) for the whole space
  `E_A ⊗ E_B`, proved by grouping pairs by class and Lemma 2).
* The register blocks of the moment matrix `Γ p q = Tr[W (C_p ⊗ D_q)]` are Gram matrices
  (`gam_block_psd`), so `∑ Y Γ ≥ 0` for positive semidefinite `Y` (Schur product theorem,
  `sum_mul_nonneg_of_psd`).
* `gyni_eq_obj`: `I_GYNI = Re ∑ objT p q Γ p q` (Lemma 3(d)).
* `gyni_le_of_dual` (`UBDuality.lean`): weak duality. `gyni_le_level` (`UBLevelMain.lean`): the same
  from the kernel-checked data of a level. `exists_lueders_form` (`UBBridge.lean`): Lemma 1 in the
  form used here (`luedersInstr = lChoi`, `IsProjFamily = IsProjMeas`).

### 3. Data and kernel checks

Data (generated by `tools/export_lean.py`): all integers scaled by `den = 16 D |GG| = 2^57`.
One natural-number literal per matrix row (packed: `R = ∑ⱼ (Φᵢⱼ + oA) 2^(bA j)`), rows of the
factor `L` (lower triangular, `c A = L Lᵀ + E`, `L = round(2^24 chol(A - τ 1))`, `c = 2^48`), and the
packed columns `PL k = ∑ⱼ Lⱼₖ X^j` (`X = 2^bX`). Checks (`UBCheck.lean`, evaluated by
`decide +kernel` in Mathlib-free files):

| check | meaning | soundness |
|---|---|---|
| `tabOK`, `coverOK`, `tabShapeOK` | class table against `clsW` (free reduction) on the word table | `tabOK_spec`, `coverOK_spec`, `cls_nil_iff` |
| `caSB`/`caOK`, `cbRA`/`cbOK` | vanishing class sums (CA), (CB) | `caOK_spec`, `cbOK_spec`, `classSum_zero` |
| `symOK` | each block symmetric | `symOK_full` |
| `traceSum` | `β = betaNum / den` | `traceSum_eq`, `sum_filter_nil` |
| `colOK` | packed columns of `L` | `colPack_eq` |
| `rowChk` | `W = c ∑ⱼ Aᵢⱼ X^j - ∑ₖ Lᵢₖ PL k + h ∑ⱼ X^j` has `N` digits, balanced digits `eⱼ` satisfy `|eⱼ| ≤ eps`, `∑ⱼ |eⱼ| ≤ 2 eᵢ` | `eChk_spec`, `psd_of_rowsChk` (with `GYNIProof.eq_zero_of_sum_pow`, `GYNIProof.posSemidef_of_gram`) |
| `params_ok`, `ones_ok`, `words_ok` | `2 (c α + N λ² + eps) < X`, offsets, word table | used in `gyni_le_level` |

Parameters: level 2: `bA = 54`, `bL = 51`, `bX = 107`; level 8: `n = 17` words, blocks `289 × 289`,
`bA = 53`, `bL = 50`, `bX = 109`, `eps < 2^74`. Every check is first re-run in exact arithmetic by a
Python mirror in `export_lean.py` (level 8: 7.5 s).

### 4. Kernel engineering (measured)

* List literals of 83k integers: 3.2 GB and recursion-limit failures. One literal per packed row:
  a 289-row block elaborates in 5–12 s at < 300 MB.
* Tail-recursive kernel loops cost about 4.5 µs per step, non-tail recursion about 35 µs per step;
  `Int.pow` is not accelerated (all powers are `Nat` powers, `pw`).
* The kernel caches `whnf` results of shared closed subterms (a list used 200 times costs the same
  as once): the row fetches inside the class-sum loops are computed once per word.
* Superlinear cost of one huge declaration: the packed-column check of a whole 289-block in one
  theorem ran > 300 s at > 3.6 GB (stopped). In theorems of 17 columns (memory is released between
  declarations) the block takes about 35 s at 1.4 GB. Likewise rows: 17 per theorem, 17 theorems per
  file (~160 s per block, 2.3 GB); class sums: one theorem per word (~31 s per register, 1.4 GB).
* In `L*/Main.lean` the chunk theorems are combined by `rowsChk_add`/`colOK_add` in sequential `have`
  steps with explicit literal counts and `attribute [local irreducible] rowsChk colOK`, so that the
  elaborator never evaluates a check (a nested term against the expected type `… 0 nN` made the
  elaborator unfold and evaluate the checks: 9.4 GB, heartbeat timeouts, exit 1).

## Reproduction

From `formal-conjectures/` (Windows, Git Bash; Python `C:\Python314\python.exe` with numpy/scipy/clarabel):

    python GYNIUpper/tools/make_cert.py 2 1e-7                       # data/cert3_L2.pkl
    python GYNIUpper/tools/averaged_cert.py GYNIUpper/data/cert3_L2.pkl GYNIUpper/data/avg_L2.pkl --pd
    python GYNIUpper/tools/export_lean.py GYNIUpper/data/avg_L2.pkl GYNIUpper/L2 L2 24 25 25 5 25
    python GYNIUpper/tools/averaged_cert.py ../publish/GYNI-Causal-Problem/src/cert3_L8_e9.pkl GYNIUpper/data/avg_L8.pkl
    python GYNIUpper/tools/run_export_L8.py 24                       # data/export_L8.pkl (+ mirror checks)
    python GYNIUpper/tools/export_lean.py --from-export GYNIUpper/data/export_L8.pkl GYNIUpper/L8 L8 24 17 289 1 17
    bash GYNIUpper/check_upper.sh 2>&1 | tee GYNIUpper/logs_upper/check_upper.log
    python GYNIUpper/tools/log_table.py GYNIUpper/logs_upper/check_upper.log

`check_upper.sh` compiles every file in dependency order through `tools/ub_step.ps1` (one Lean process
at a time; before each process it waits, polling every 60 s, until no other `lean.exe` runs and
Available MBytes ≥ expected peak + 1.5 GB), prints `#print axioms` and greps for forbidden keywords.
Prerequisites (not rebuilt): `GYNIProof/{IntLit,Data,Core,Defs,BlockPSD}.olean`,
`GYNIUpper/Lueders{Choi,Dilation,NormalForm}.olean`.

## Deviations and side effects

* Two calibration or trial compiles exceeded their declared peak: the monolithic packed-column
  check (reached 3.7 GB against 2.5 GB declared; stopped by me) and one failed version of
  `L8/Main.lean` (9.4 GB peak working set against 3.8 GB declared; ended by itself with exit 1). Both
  are fixed in the final files (see section 4); the final run stays within the declared peaks.
* Importing `certify3.py` from the source repository made Python write two bytecode caches,
  `publish/GYNI-Causal-Problem/src/__pycache__/{certify3,hier3}.cpython-314.pyc` (ignored by that
  repository's `.gitignore`). They were not deleted; the tools now set `sys.dont_write_bytecode`.
